        Platforms & browser automation

        Paste the OAuth Client ID and Client Secret for each platform, save the keys, then press Connect. Tokens are stored locally in the studio data directory.

        YouTube Agent Credentials

        Google OAuth Desktop app credentials. The agent gets full studio scopes — upload, publish, edit visibility, manage videos.

        Instagram Agent Credentials

        Meta Instagram OAuth credentials to manage Instagram content.

        Facebook Agent Credentials

        Meta Facebook OAuth credentials to manage Facebook pages.

        Google Agent Credentials

        Google OAuth credentials for Gmail, Drive/Docs, Calendar, Photos and Business Profile. Reconnect after upgrading so the new scopes are granted.

        GitHub Agent Credentials

        Personal access token (classic or fine-grained) with repo/issues/pull-request access. You can also set GITHUB_TOKEN or GH_TOKEN in the environment.
